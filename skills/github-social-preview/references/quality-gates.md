# GitHub social-preview quality gates

## Technical gates

- File path is exactly `assets/github-social-preview.png`.
- File is a valid PNG.
- Dimensions are exactly 1280 × 640.
- File size is below 1,000,000 bytes.
- A 640 × 320 temporary thumbnail can be created and opened.

## Brand gates

- The logo is the exact repository asset.
- Logo proportions, colours, internal geometry, and orientation are unchanged.
- Palette and motifs are traceable to the repository identity.
- Product name, tagline, and supporting line match their confirmed source exactly.
- No generated layer attempts to reproduce the logo or text.

## Communication gates

- One visual idea is immediately legible.
- Product name and tagline survive 50% scale.
- Supporting copy is omitted when it becomes small or redundant.
- Claims are confirmed by the prompt or repository.
- The composition communicates the product without fake code, fake UI, or decorative AI shorthand.

## Craft gates

- Alignment and spacing feel deliberate.
- Important content respects safe margins.
- Contrast and hierarchy remain clear after compression.
- Logo and typography are crisp at full size.
- Generated textures or illustrations contain no malformed or distracting detail.
- The image feels specific to the repository rather than marketplace-generic.

## Repository gates

- Only the requested PNG is created or replaced.
- README and repository settings remain unchanged.
- No commit, push, issue, release, upload, or social-preview setting change occurs without explicit follow-up approval.

Any failed gate requires revision before delivery.
