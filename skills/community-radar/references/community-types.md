# Community selection guide

Use this as a coverage prompt, not a mandatory channel list.

| Community type | Strong signals | Common risks | Useful posture |
|---|---|---|---|
| Hacker News | technical novelty, credible implementation detail, active problem discussion | launch fatigue, repetition, defensive promotion | answer concretely; submit only when substance is ready |
| Reddit | focused subreddits, repeated questions, visible rules and active moderation | self-promotion rules, duplicate posting, hostile reception | participate before linking; answer the exact question |
| Lobsters | deep engineering fit, established member context | invitation barrier, narrow norms, low tolerance for promotion | technical discussion over launch copy |
| GitHub issues/discussions | users already working near the problem, reproducible requests | hijacking unrelated projects, maintainer burden | contribute fixes, context, or interoperability detail |
| Discord/Slack | concentrated practitioners and rapid feedback | private access, ephemeral context, community fatigue | observe norms; ask permission; summarize privately |
| X | current practitioner conversations and public build updates | context collapse, shallow virality incentives | reply with evidence; avoid unsolicited link drops |
| LinkedIn | professional role and operational pain discussions | generic thought leadership, sales perception | share lessons and constraints, not hype |
| Specialist forums | high domain overlap and persistent searchable questions | local rules, older interfaces, reputation requirements | solve first; disclose affiliation |
| Newsletters/podcasts | recurring editorial interest and trusted curation | pitch volume, long lead time | offer evidence or a useful story only when ready |
| Meetups/conferences | direct practitioner learning and feedback | geography, timing, sponsor bias | contribute a talk, demo, or help session |

## Community map evidence

For each included community, capture:

- a direct home or relevant-section URL;
- current activity evidence, not an assumed reputation;
- an official rules or norms source when promotion is contemplated;
- target-audience overlap and its evidence state;
- confidence and access limitations.

Exclude a famous channel when no current audience or conversation evidence connects it to the product.
