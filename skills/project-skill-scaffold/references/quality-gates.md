# Quality gates

- The stability gate passed from inspected repository evidence.
- Required authoritative paths exist and hashes match generation-time values.
- Optional absent paths are labeled optional.
- Milestone IDs are unique; each has goal, entry, evidence, and exit criteria.
- Requirements, observed status, unknowns, and future work remain distinct.
- `SKILL.md` references sources rather than copying large specifications.
- No permanent branch, commit SHA, installed plugin version, relative deadline, or completion claim is embedded.
- Specialist dependencies have levels, jobs, and extraction-safe fallbacks or blockers.
- Generated Skill passes Skill Creator-compatible structural checks.
- Generated validator and state inspector execute successfully.
- The inspector labels documented, observed, unverified, and conflicting evidence.
- No milestone is completed from filename presence.
- Fresh-session starter names authority, next candidate slice, required specialists, re-verification, and finish contract.
- Refresh writes a separate candidate and diff.
- Unmanaged and edited generated files are byte-preserved.
- Extraction test passes without CodexToolkit files.
- Repository publication occurs only through an authorized focused branch/draft-PR workflow.
