# Target profiles

Profiles are prompts for a target contract, not timeless platform specifications. Confirm current platform rules when exact crops or limits matter.

## Transparent banner

- Require a real transparent wordmark/logo source.
- Use proportional `contain` placement and transparent padding.
- Measure both alpha-channel presence and actual transparent pixels.
- Inspect on light, dark, and checkerboard backgrounds.

## Profile or social banner

- Obtain exact current canvas and crop/safe-area rules.
- Identify protected content and inspect every named desktop/mobile crop.
- Keep essential marks and copy out of avatar/overlay regions.
- Do not invent supporting copy or a new campaign concept.

## Documentation header or release card

- Obtain consuming layout width, background, theme variants, and relative path.
- Prefer simple large elements that survive reduced rendering.
- Verify the final relative reference only when documentation editing is in scope.

## Finished social canvas

The adapter may resize, pad, compress, or review already approved complete artwork. Repository-aware GitHub social-preview composition, product claims, exact 1280 × 640 narrative, and thumbnail review belong to `$github-social-preview`.

## Custom

Require exact dimensions, format, byte ceiling, alpha/background behavior, safe-area coordinates, protected elements, allowed crops, and preview sizes. Do not guess a platform contract.
